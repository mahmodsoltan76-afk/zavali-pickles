# Zoali Pickles — فروشگاه ترشیجات زوالی

نسخه آماده برای GitHub Pages.

## فایل‌ها
- `index.html` — صفحه اصلی
- `style.css` — طراحی و ریسپانسیو
- `script.js` — محصولات، جستجو، فیلتر، صفحه محصول و سبد خرید
- `logo.svg` — لوگوی زوالی
- `.nojekyll` — برای انتشار استاتیک

## انتشار در GitHub Pages
1. همه فایل‌ها را در ریشه repository آپلود کن.
2. در GitHub برو به `Settings → Pages`.
3. در بخش Source گزینه `Deploy from a branch` را انتخاب کن.
4. Branch را روی `main` و Folder را روی `/ (root)` بگذار.
5. Save را بزن.
